# 🔥 Thermal Electrical Panel Detection System

A two-module system for detecting **hotspots and overheating components** in electrical panels using thermal imaging — combining Python-based Digital Image Processing (DIP) algorithms with a Java-based interactive dashboard GUI.

---

## 📁 Repository Structure

```
Thermal-Eletical-Panel-Detect/
│
├── THERMAL PROJECT/          # Python — DIP Algorithms & ML Models
│
└── Thermal Dashboard_TP/     # Java — JavaFX GUI + OpenCV + Maven
```

---

## 📦 Module 1: `THERMAL PROJECT` — DIP Concepts & Algorithms

### Overview
This module implements core **Digital Image Processing** techniques and **Machine Learning** models to analyze pre-captured thermal images of electrical panels and identify hotspot regions.

### 🔬 Techniques & Algorithms Used

| Technique | Description |
|---|---|
| **Edge Detection** | Identifies boundaries of overheating components using Canny / Sobel operators |
| **Heatmap** | Maps pixel intensity to thermal color scales (e.g., roi,preprocessing) for visual diagnosis |
| **Machine Learning**| Random forest  |

### 🧪 Input
- Pre-captured thermal image dataset (`.jpg`, `.png`, or infrared image formats)

### 🛠️ Tech Stack
- **Language:** Python
- **Environment:** Jupyter Notebook (`.ipynb`)
- **Key Libraries:**
  - `OpenCV` — image reading, preprocessing, edge detection
  - `NumPy` — array operations and pixel manipulation
  - `Matplotlib` — heatmap visualization and color mapping
  - `scikit-learn` / `TensorFlow` / `PyTorch` — ML/DL model training and inference

### 📌 Key Notebooks
- Thermal image loading and preprocessing
- Edge detection pipeline
- Color-mapped heatmap generation
- Hotspot classification model

## 📦 Module 2: `Thermal Dashboard_TP` — GUI Dashboard

### Overview
A fully interactive desktop application built with **JavaFX** that allows users to load thermal images, run image processing operations, and visualize detection results through a professional GUI.

### 🖥️ Features
- Load and display thermal images from local storage
- Real-time image processing via **OpenCV** integration
- Hotspot highlighting and annotation on-screen
- Modular, clean GUI built with **JavaFX**
- Easily buildable and runnable via **Apache Maven**

### 🛠️ Tech Stack

| Technology | Role |
|---|---|
| **Java** | Core application language |
| **JavaFX** | Desktop GUI framework — scenes, controllers, FXML layouts |
| **OpenCV (Java bindings)** | Image loading, processing, and analysis |
| **Apache Maven** | Project build, dependency management, packaging |

### 📂 Project Structure (Maven Standard Layout)
```
Thermal Dashboard_TP/
├── pom.xml                    # Maven build config & dependencies
├── src/
│   ├── main/
│   │   ├── java/              # Java source files (controllers, logic)
│   │   └── resources/         # FXML layouts, CSS styles, assets
│   └── test/
│       └── java/              # Unit tests
└── target/                    # Compiled output (generated by Maven)
```

### ⚙️ Build & Run

**Prerequisites:**
- Java JDK 21
- Apache Maven 3.6+
- OpenCV native library installed

**Steps:**
```bash
# 1. Clone the repository
git clone https://github.com/jaygupta2107/Thermal-Eletical-Panel-Detect.git
cd "Thermal-Eletical-Panel-Detect/Thermal Dashboard_TP"

# 2. Build the project
mvn clean install

# 3. Run the application
mvn javafx:run
```
